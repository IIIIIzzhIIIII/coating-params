# 建筑喷涂数据参数库

特殊功能性涂层参数查询工具，单页面静态站点（`index.html` + `img/`），手机扫码即可使用，可直接部署在 GitHub Pages。

## 功能交付说明

| 模块 | 说明 |
| --- | --- |
| 顶部栏 | 橙色 `#FF6B35` 标题栏（副标题「特殊功能性涂层查询系统」）+ 搜索框，`position: sticky` 滚动固定；右上角二维码入口 |
| 二维码 | 点击入口弹出「扫码查看 / 分享」，页面内实时生成当前网址的 QR 码（`qrcode-generator` MIT，已内联，无外部请求），支持复制链接 |
| 关键词搜索 | 对编号、分类、场景、性能指标、膜厚、材料/标准、来源做全文模糊匹配，120ms 防抖 |
| 分类筛选 | 全部 / 防静电 / 防火阻燃 / 防爆抗爆 / 绝缘导热 / 防腐 / 防水 / 耐磨防滑，横向滑动标签 |
| 场景筛选 | 厂房 / 隧道 / 仓库 / 配电柜 / 屋面 / 地坪 / 管道，按场景关键词匹配，可与分类叠加 |
| 数值范围筛选 | 折叠面板，11 项指标均可按 min/max 过滤并叠加：膜厚(μm)、耐火极限(h)、抗冲击(kPa)、表面电阻指数(10ⁿΩ)、绝缘电阻指数(10ⁿΩ)、导热系数(W/(m·K))、拉伸强度(MPa)、抗压强度(MPa)、耐磨性(g)、防滑系数、耐久年限(年)。条件以标签形式展示，可单独移除；`mm` 自动 ×1000 折算，范围值取最小值 |
| 卡片列表 | 编号、分类、场景、橙色加粗核心性能、蓝色膜厚标签、绿色来源标签、「角度 / 压力」参考值标签，右侧为该工作场景的实景配图；点击平滑展开/收起完整字段 |
| 空状态 | 无匹配时显示「未找到匹配参数 / 请调整筛选条件」 |
| 底部栏 | 固定显示「共收录 50 条参数 | 当前显示 N 条」+ 免责声明 |

## 场景配图

- 素材存放在 `png/`，文件名与使用场景一一对应（如 `聚氨酯防水涂料Ⅰ型(屋面卫生间).jpg`、`Im3土壤埋地-环氧煤沥青体系(埋地管道).jpg`），共 46 张。
- 50 条记录 → 46 张图；3 处就近复用：`QZDS-049`（镀锌钢，C3）用 C3 中等腐蚀图、`QZDS-040`（外墙）用外墙防水图、`QZDS-042`（地下隧道）用电缆隧道图；`QZDS-025/026`、`027/028` 场景相同共用一张。
- 页面加载 `img/01.webp` ~ `img/46.webp`：自动识别并裁掉旧素材外层的暗底 + 白色相框（无边框实景照保持原构图），按卡片比例居中裁切为 240×344，WebP 质量 80，单张约 2–24KB，合计约 350KB，`loading="lazy"` 懒加载。
- 映射表写在 `index.html` 的 `SCENE_IMG`（场景名 → 图片编号），新增素材时替换同名文件并重新生成对应 `img/xx.webp` 即可。

## 数据

- 共 50 条，编号 `QZDS-001` ~ `QZDS-050`，全部内置在 `index.html` 的 `DATA` 数组中，无后端、无数据库。
- 喷涂角度、喷涂压力：国标无统一规定，按喷涂方式给出**行业通用参考值**（垂直 90°、喷距 200–500mm、空气喷涂 0.2–0.6MPa、无气喷涂 15–25MPa），卡片与详情均标注「参考值」，并注明非国标强制、施工以设备与材料厂家说明为准。
- 膜厚字段保留原始描述，同时在页面加载时换算为 μm（`toMicron()`），仅用于筛选比较，不改变展示文本。
- 各项性能指标的数值在加载时统一抽取（`METRICS[].pick`），用于范围筛选；无该项数值的条目在该条件启用时会被过滤掉。

## 技术实现

- 页面 CSS/JS/数据全部内联在 `index.html`；配图为本地相对路径资源，无任何第三方请求。
- 移动端优先，适配 375–430px 屏幕，桌面端在 600px 宽度内居中。
- 无构建步骤、无依赖，直接静态托管。

## 本地预览

```bash
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/
```

## 部署

仓库根目录放置 `index.html`、`img/`，Settings → Pages → Source 选择 `main` 分支根目录即可。

访问地址：`https://<用户名>.github.io/<仓库名>/`
